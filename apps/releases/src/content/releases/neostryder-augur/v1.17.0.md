### Added

- [Visible] [Platform] **Settings has a Release channel choice: Stable, the default, or Early.** Early installs a new build of the main branch after each merge so you can test features before a release is tagged, and these builds can break. Switching back to Stable keeps the installed version until a newer tagged release appears.
- [Visible] [UI] **Added a node view that edits each activity's model mix as a donut, with undo history and reduced motion support.** Catalog adds now keep existing levels and respect refusals. Copy and suggest each undo in one step, and small positive shares stay visible. Pointer cancellation, keyboard batching, selection isolation, search drafts, tooltips, phone controls, and focus in the node view were fixed.
- [Visible] [Providers] **Added Claude API key support with a key test.** Existing route-specific keys still apply. Usage refresh for the Claude API provider now stays offline. Route planning checks that baseUrl is valid, and requests accept a baseUrl that ends in a v1 path. Test key results now last only for the current session.
- [Visible] [Platform] **`augur run` and the augur_run tool take a per-job effort and an answer schema.** The effort overrides the route's setting for that job. Codex and Grok routes enforce the JSON Schema with native structured output, other routes get it in the prompt, and an answer that fails it adds a warning to the job.
- [Visible] [Providers] **Augur reads the Cogitator gateway's catalog endpoint with the manage key.** Entries that declare their uses replace the shipped descriptions, role chains come from the live roles, and each peer's models are described by that peer's own catalog. A gateway or peer without the endpoint keeps the shipped descriptions.
- [Visible] [UI] **In the Node view, drag a model from the full list onto the dial to add it, or back to the list to remove it.** Buttons and the Delete key do the same, and each change can be undone. A drop that cannot work explains why in a dialog, and removing the last model or adding a blocked model asks first.
- [Visible] [UI] **Augur Chat is a chat page for every chat model you have set up.** The service serves it at `/chat/` beside the web app, it opens with the same web token, and a phone can add it to the home screen as an app. Models on your own network are listed first. Replies stream in as Markdown, a model's reasoning sits in a block that folds away, and each reply shows the tokens it used and its cost when known. A message can carry up to 8 attachments of 25 MB each. Saved chats are grouped by date, pinned chats stay on top, and search finds words in any message. They are stored unencrypted in the service's data folder, as [docs/chat.md](docs/chat.md) describes.
- [Visible] [Security] **Each chat has a data level, and a chat can be temporary.** Every send is checked against the same rules as a job, and only models cleared for the chat's level (public, internal, sensitive, or regulated) can answer it. Once a chat has messages, its level can go up but not down, because its history goes to whichever model answers next. A temporary chat is kept in the service's memory only and is gone when it is deleted or the service restarts. The web token opens every saved chat.
- [Visible] [UI] **Chats branch, and each chat keeps its own model settings.** Editing a message or writing a reply again, with the same model or another, starts a branch, and a `1/2` switcher steps between versions. The settings drawer holds a system prompt and the settings the model offers, each with a plain explanation and the model's default, and only the values you change are sent.
- [Visible] [UI] **The chat has a command palette and keyboard shortcuts.** Ctrl+K (Cmd+K on a Mac) finds any command, recent chat, or model, and other keys stop a reply or reopen the last message for editing. Preferences cover the theme and text size along with a few display switches, and a JSON skin stored in the browser under `augur.chat.skin` re-themes every color.
- [Visible] [UI] **Augur Chat has users, each with their own chats, token, and model list.** The owner adds users and devices with `augur web user` and `augur web device` or from the Manage users panel in the chat page, and each gets an `augc_` token that opens only the chat. A user has a list of allowed models, a data-tier cap, and an optional daily message limit. People see only their own chats, and existing chats stay the owner's.
- [Visible] [Security] **Augur Chat can run on its own https listener that serves only the chat.** Set `web.chatPort` to open a second listener that serves the chat page and `/api/chat/*`, returns 404 for everything else, and does not accept the owner's web token. With `web.accessTeam` and `web.accessAud` set, people signed in through Cloudflare Access open the chat with no token, matched to a user by email.
- [Visible] [Providers] **Model picks now count ChatGPT use against the Codex weekly allowance.** Until now `chatgpt/web` always showed full headroom, so research picks kept landing on it however much of the shared OpenAI allowance Codex had used. The pick reason for `chatgpt/web` now says its figures are shared with Codex.
- [Internal] [Platform] **The service runs a chat service behind `/api/chat/`.** It lists the chat-capable routes with what the rules allow each, keeps saved chats in SQLite and temporary ones in memory, stores attachments, and streams each reply from a process of its own, so the provider key never enters the service process.

### Fixed

- [Internal] [Platform] **The service no longer keeps stale premium gate and surplus-window state when a virus scanner or another program briefly holds gate-state.json open on Windows.** Both writes to gate-state.json now go through the existing atomic write with retries instead of a bare rename or direct write that dropped errors, and an unreadable current file is rewritten instead of trusted. The service package test timeout is now 60 seconds instead of 5 because a loaded Windows CI runner took 10 to 40 seconds for tests that finish in under a second locally.
- [Visible] [Windows] **Refreshing Jev or Claude usage no longer shows a window that looks like a sign-in prompt.** Augur reads the account page in a background window, and on Windows that window used to sit on screen for about 30 seconds before closing. The window now opens off screen and ignores mouse input, and you still sign in through the sign-in window that Settings opens.
- [Visible] [Windows] **The TypeSafe sign-in window no longer closes by itself before you finish logging in.** A sign-in page can ask its own window to close, and that request used to shut the Augur sign-in window. The window now ignores the request and stays open until Augur has read the balance or you close it.
- [Visible] [Windows] **The TypeSafe sign-in window writes a local `signin.log` trace of its navigation and account-reading results.** The trace contains URL hosts and paths without query strings or fragments, and it never records page text, cookies, or tokens.
- [Visible] [Windows] **When pressing Update leaves Augur on the old version with no message, two log files now show what happened.** Augur writes each step to `update.log` in %APPDATA%\com.neostryder.augur: the check, the download size, the handoff to the installer, and any error. The installer writes `update-install.log` in %LOCALAPPDATA%\Augur with the steps it takes to stop the Augur service before copying files, and neither file holds passwords, tokens, or page text.
- [Visible] [UI] **The TypeSafe and Claude sign-in window stays open until Augur reads your account page (the credit balance, for TypeSafe), then closes itself.** It no longer gives up after 15 minutes, and Augur waits 30 seconds or for a page change before retrying a failed reading. A downloading update now waits for you to close the window before installing and restarting Augur.
- [Visible] [UI] **Node view search keeps the cursor and selection while you type.** Results update with each keystroke, and model search matches names, providers, and descriptions regardless of case and punctuation. A message shows when nothing matches, and Escape clears the search first.
- [Visible] [UI] **Switching Model rules to Node view no longer flickers.** The page builds the Node view first and swaps once, and the dial's entrance animation no longer replays on each redraw.
